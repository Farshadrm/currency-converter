# Currency Converter App

A simple React application that converts currencies using exchange rates. Built with modern React practices, Tailwind CSS for styling, and written in TypeScript for improved developer experience and type safety.

## Features

-   Convert between multiple currencies

-   Type-safe components using TypeScript
-   Tailwind CSS for utility-first styling

## Technologies Used

-   [React](https://react.dev/learn) – Frontend framework
-   [Tailwind CSS](https://tailwindcss.com/docs) – Utility-first CSS framework
-   [TypeScript](https://www.typescriptlang.org/docs) – Strongly typed JavaScript

## Getting Started

### Prerequisites

-   Node.js (v16 or higher recommended)
-   npm or yarn
